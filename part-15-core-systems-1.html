مستندات پروژه-محور Nexus

بخش ۱۵: سیستم‌های هسته‌ای (۱ از ۲)

آشنایی با سیستم‌های بنیادی که دنیای Nexus را مدیریت و نگهداری می‌کنند.

کارگران پشت صحنه

علاوه بر سیستم‌هایی که منطق اصلی اپلیکیشن شما را پیاده‌سازی می‌کنند، پکیج `nexus` مجموعه‌ای از سیستم‌های هسته‌ای را ارائه می‌دهد که وظایف مدیریتی و زیرساختی را بر عهده دارند. این سیستم‌ها مانند کارگران پشت صحنه یک تئاتر هستند؛ شما آن‌ها را نمی‌بینید، اما بدون آن‌ها هیچ نمایشی اجرا نمی‌شود.

در این بخش، به بررسی سیستم‌هایی می‌پردازیم که مسئولیت چرخه حیات، مدیریت حافظه و زمان‌بندی را بر عهده دارند.

`LifecycleSystem`: اجرای `onInit` و `onDispose`

این سیستم بسیار ساده اما حیاتی است. وظیفه آن، اجرای متدهای `onInit` و `onDispose` از `LifecycleComponent` است. 


// از پکیج nexus

class LifecycleSystem extends System {
  @override
  bool matches(Entity entity) {
    return entity.has();
  }

  // وقتی یک موجودیت منطبق به دنیا اضافه می‌شود، onInit را فراخوانی می‌کند
  @override
  void onEntityAdded(Entity entity) {
    final lifecycle = entity.get()!;
    lifecycle.onInit?.call(entity);
  }

  // وقتی یک موجودیت منطبق از دنیا حذف می‌شود، onDispose را فراخوانی می‌کند
  @override
  void onEntityRemoved(Entity entity) {
    final lifecycle = entity.get()!;
    lifecycle.onDispose?.call(entity);
  }
  // ...
}

این سیستم به شما اجازه می‌دهد تا منطق راه‌اندازی و پاک‌سازی را به خود موجودیت‌ها متصل کنید، که باعث تمیزتر شدن کد می‌شود.

`GarbageCollectorSystem`: جلوگیری از نشت حافظه

این سیستم، رفتگر دنیای Nexus است. این سیستم به صورت دوره‌ای (مثلاً هر ۲ ثانیه) تمام موجودیت‌ها را بررسی می‌کند و آن‌هایی را که `LifecyclePolicyComponent` دارند، ارزیابی می‌کند. 


// از پکیج nexus

class GarbageCollectorSystem extends System {
  // ...
  void runGc(double dt) {
    // ...
    for (final entity in entitiesToCheck) {
      final policy = entity.get();
      // ...
      // اگر موجودیت دائمی نباشد و شرط حذف آن برقرار باشد...
      if (!policy.isPersistent && policy.destructionCondition(entity)) {
        // ... آن را برای حذف علامت‌گذاری می‌کند
        entitiesToRemove.add(entity.id);
      }
    }
    // ...
  }
}

استفاده صحیح از `LifecyclePolicyComponent` به همراه این سیستم تضمین می‌کند که موجودیت‌های موقتی (مانند افکت‌های بصری، گلوله‌ها در بازی، یا آیتم‌های موقت UI) پس از پایان عمرشان به طور خودکار از حافظه پاک می‌شوند.

`TimerSystem`: موتور زمان‌بندی

این سیستم، منطق `TimerComponent` را پیاده‌سازی می‌کند. در هر فریم، `TimerSystem` تمام `TimerTask`های فعال را پیدا کرده و `elapsedTime` آن‌ها را به‌روز می‌کند. 


// از پکیج nexus

class TimerSystem extends System {
  @override
  bool matches(Entity entity) {
    return entity.has();
  }

  @override
  void update(Entity entity, double dt) {
    final timerComponent = entity.get()!;
    // ...
    for (final task in timerComponent.tasks) {
      task.elapsedTime += dt;

      if (task.onTickEvent != null) {
        world.eventBus.fire(task.onTickEvent);
      }

      if (task.elapsedTime >= task.duration) {
        // وقتی زمان تمام شد، رویداد onComplete را منتشر می‌کند
        world.eventBus.fire(task.onCompleteEvent);

        if (task.repeats) {
          task.elapsedTime -= task.duration; // ریست برای تکرار بعدی
        } else {
          tasksToRemove.add(task); // علامت‌گذاری برای حذف
        }
      }
    }
    // ...
  }
}

همانطور که در بخش ۱۲ دیدیم، این سیستم به همراه `TimerComponent` یک ابزار فوق‌العاده قدرتمند برای ساخت انیمیشن‌ها و منطق‌های چندمرحله‌ای و زمان‌بندی شده است.

`PersistenceSystem`: ذخیره و بازیابی خودکار

این سیستم با `PersistenceComponent` کار می‌کند تا فرآیند ذخیره و بازیابی داده‌ها را خودکار کند.

  • در زمان راه‌اندازی (`init`): سیستم تمام داده‌های ذخیره شده را از `StorageAdapter` (مثلاً `SharedPreferences`) می‌خواند و موجودیت‌ها و کامپوننت‌های مربوطه را بازسازی می‌کند.
  • در پاسخ به `SaveDataEvent`: سیستم تمام موجودیت‌هایی را که `PersistenceComponent` دارند پیدا کرده، کامپوننت‌های سریالایزبل آن‌ها را به JSON تبدیل کرده و در حافظه دائمی ذخیره می‌کند.

این سیستم شما را از نوشتن کدهای تکراری برای ذخیره و بازیابی داده‌ها بی‌نیاز می‌کند و به شما اجازه می‌دهد تا با افزودن یک کامپوننت، ماندگاری را به هر موجودیتی اضافه کنید.
