مستندات پروژه-محور Nexus

بخش ۱۰: مثال عملی - ماژول دسته‌بندی (۳ از ۴)

پیاده‌سازی منطق ساخت و ویرایش داده‌ها در `CategorySystem`.

جان بخشیدن به تعاملات

در بخش قبل، دیدیم که چگونه لایه UI رویدادهای `CreateCategoryEvent` و `UpdateCategoryEvent` را به دنیای منطق ارسال می‌کند. اکنون، به سراغ `CategorySystem` می‌رویم تا ببینیم این سیستم چگونه به این رویدادها واکنش نشان می‌دهد و وضعیت دنیای ما را تغییر می‌دهد.

گوش دادن به رویدادها در `CategorySystem`

مانند هر سیستم رویداد-محور دیگری، `CategorySystem` در متد `onAddedToWorld` خود، شنونده‌های لازم را برای رویدادهای مورد نظرش ثبت می‌کند. 


// File: lib/src/category/category_module.dart

class CategorySystem extends System {
  @override
  void onAddedToWorld(NexusWorld world) {
    super.onAddedToWorld(world);
    // ثبت شنونده برای رویدادهای مختلف
    listen(_onCreate);
    listen(_onUpdate);
    listen(_onStartEdit);
    listen(_onCancelEdit);
    listen(_onSwipe); // در بخش بعد بررسی می‌شود
  }
  // ...
}

پیاده‌سازی منطق ساخت (Create)

متد `_onCreate` مسئولیت رسیدگی به رویداد `CreateCategoryEvent` را بر عهده دارد. این متد چندین کار مهم انجام می‌دهد: 


// File: lib/src/category/category_module.dart -> class CategorySystem

void _onCreate(CreateCategoryEvent event) {
  // 1. یک موجودیت جدید برای آیتم می‌سازد
  final newItem = Entity()
    ..add(CategoryItemComponent(
      id: DateTime.now().millisecondsSinceEpoch.toString(), // شناسه یکتا
      name: event.name,
      description: event.description,
    ))
    ..add(LifecyclePolicyComponent(isPersistent: true));
  world.addEntity(newItem); // موجودیت را به دنیا اضافه می‌کند

  // 2. موجودیت مدیر لیست را پیدا می‌کند
  final listManagerEntity = /* ... */;
  final listComp = listManagerEntity.get()!;

  // 3. شناسه آیتم جدید را به لیست allItems اضافه می‌کند
  final updatedList = List.from(listComp.allItems)..add(newItem.id);

  // 4. کامپوننت لیست را با لیست جدید به‌روزرسانی می‌کند
  listManagerEntity.add(ListComponent(
    listId: listComp.listId,
    allItems: updatedList,
    visibleItems: listComp.visibleItems, // فعلاً لیست قابل مشاهده را دست نمی‌زنیم
  ));
  
  // 5. یک رویداد برای باز-محاسبه لیست قابل مشاهده ارسال می‌کند
  world.eventBus.fire(
      UpdateListFilterEvent(listId: listComp.listId, filterCriteria: {}));
}

این جریان بسیار مهم است. سیستم مستقیماً `visibleItems` را تغییر نمی‌دهد. در عوض، با به‌روزرسانی `allItems` و سپس ارسال یک رویداد، مسئولیت باز-محاسبه لیست قابل مشاهده را به `ListStateSystem` واگذار می‌کند. این کار باعث می‌شود که منطق فیلتر، جستجو و مرتب‌سازی در یک مکان متمرکز باقی بماند.

پیاده‌سازی منطق ویرایش (Update)

منطق ویرایش بسیار ساده‌تر است. متد `_onUpdate` رویداد `UpdateCategoryEvent` را دریافت می‌کند که حاوی شناسه موجودیت مورد نظر و داده‌های جدید است. 


// File: lib/src/category/category_module.dart -> class CategorySystem

void _onUpdate(UpdateCategoryEvent event) {
  // 1. موجودیت را با استفاده از شناسه پیدا می‌کند
  final itemEntity = world.entities[event.entityId];
  if (itemEntity == null) return;

  final currentItem = itemEntity.get()!;
  
  // 2. یک نمونه جدید از کامپوننت را با داده‌های به‌روز شده اضافه می‌کند
  // این کار به طور خودکار جایگزین کامپوننت قبلی می‌شود
  itemEntity.add(CategoryItemComponent(
    id: currentItem.id, // شناسه ثابت باقی می‌ماند
    name: event.newName,
    description: event.newDescription,
  ));
  
  // 3. کامپوننت نشانگر "در حال ویرایش" را حذف می‌کند (اگر وجود داشته باشد)
  itemEntity.remove();
}

به‌روزرسانی کامپوننت‌ها

در Nexus، برای به‌روزرسانی یک کامپوننت، شما یک نمونه جدید از آن را با داده‌های جدید می‌سازید و به موجودیت `add` می‌کنید. فریم‌ورک به طور خودکار تشخیص می‌دهد که یک کامپوننت از همان نوع از قبل وجود دارد و آن را با نمونه جدید جایگزین می‌کند. این رویکرد به حفظ تغییرناپذیری (immutability) داده‌ها کمک می‌کند.

اکنون اپلیکیشن ما قابلیت خواندن، ساخت و ویرایش دسته‌بندی‌ها را دارد. در بخش نهایی این مجموعه، به سراغ منطق حذف آیتم‌ها با استفاده از ویجت `Dismissible` و انیمیشن‌های خروج خواهیم رفت.
